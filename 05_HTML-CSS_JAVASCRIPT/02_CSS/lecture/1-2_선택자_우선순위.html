선택자 우선순위

한 태그에 여러 CSS 규칙이 겹칠 때 브라우저는 정해진 순서로 승자를 고른다. "분명히 CSS를 썼는데 적용이 안 된다"는 문제의 대부분이 여기서 나온다.

1. 우선순위 사다리

 (낮음)  태그 선택자        p { }
   │     클래스 선택자      .box { }
   │     아이디 선택자      #main { }
   │     인라인 스타일      style="..."
 (높음)  !important
위로 갈수록 강하다. 순위가 다르면 작성 순서는 아무 의미가 없다.

2. 같은 순위일 때 — 나중에 쓴 것이 이긴다

.later-wins { color: blue; }   /* 먼저 */
.later-wins { color: green; }  /* 나중 — 이쪽이 적용된다 */

초록색으로 보인다.

3. 순위가 다를 때 — 구체적인 쪽이 이긴다

.lower  { background: yellow; }  /* 클래스, 먼저 작성 */
#higher { background: orange; }  /* 아이디, 나중 작성 */

아이디가 이겨서 주황색이다.

4. 선택자를 겹쳐 쓰면 더 구체적이 된다

같은 클래스라도 앞에 무언가를 더 붙이면 그만큼 구체적이 되어 이긴다. 이것을 명시도(specificity)라고 한다.
.a       { color: gray; }     /* 클래스 1개 */
p.a      { color: purple; }   /* 태그 1 + 클래스 1 */
div p.a  { color: crimson; }  /* 태그 2 + 클래스 1 — 가장 구체적 */

가장 구체적인 div p.a가 이겨서 진홍색이다.

5. 인라인 스타일과 !important

<p class="important-test" style="background: yellowgreen;">

인라인 스타일이 클래스를 이겨서 연두색이다. 

.important-win { background: blue !important; }

!important가 인라인 스타일까지 이겨서 파란색이다.

!important는 모든 걸 무시하고 이기기 때문에 편해 보이지만, 한 번 쓰기 시작하면 그걸 이기려고 또 !important를 쓰게 된다. 우선순위 문제는 !important가 아니라 선택자를 고쳐서 푸는 것이 원칙이다.
