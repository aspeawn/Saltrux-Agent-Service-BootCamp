CSS 개요

1. CSS를 HTML에 적용하는 3가지 방법

방법 1. 인라인 스타일

태그에 style 속성을 직접 쓴다. 해당 태그 하나에만 적용되며 우선순위가 매우 높다.
<p style="color: red;">

인라인 스타일로 빨갛게 칠한 문단이다.

방법 2. 내부 스타일 시트

head 안에 style 태그로 작성한다. 이 HTML 파일 하나에만 적용된다.
<style> p { color: blue; } </style>

지금 이 파일이 쓰고 있는 방식이다. 위쪽 head를 열어보면 확인할 수 있다.

방법 3. 외부 스타일 시트

별도의 .css 파일로 분리하고 link 태그로 연결한다. 여러 HTML이 같은 css를 공유할 수 있다.
<link rel="stylesheet" href="selector2.css">

실무에서 기본이 되는 방식이다. 1-1번 파일에서 실제로 사용해 본다.

2. 캐스케이딩(Cascading)

CSS의 C는 Cascading, 즉 '위에서 아래로 흐른다'는 뜻이다. 한 요소에 여러 규칙이 겹치면 브라우저가 우선순위를 따져 하나를 고른다.
p.cascade { color: green; }  /* 태그 + 클래스 : 더 구체적 */
.cascade    { color: orange; } /* 클래스만 : 덜 구체적 */

나중에 쓴 orange가 아니라 더 구체적인 green이 적용된다.

왜 이렇게 되는지는 1-2번 파일(선택자 우선순위)에서 규칙으로 정리한다. 여기서는 "CSS는 겹쳐 쓸 수 있고, 겹치면 규칙에 따라 하나가 이긴다"는 것만 기억한다.

3. 단위

아래 상자들은 모두 화면상 같은 200px로 보이지만, 기준이 서로 다르다. 브라우저 창의 가로 폭을 줄였다 늘였다 하면서 어떤 상자가 따라 움직이는지 확인한다.

px (절대 단위)

width: 200px;
px : 창을 줄여도 그대로다

% (부모 기준 비율)

width: 50%;
% : 부모 너비의 절반이다

em (부모 글자 크기 기준)

.parent { font-size: 20px; }  .em { width: 10em; }
부모 (font-size: 20px)
em : 20px * 10 = 200px

rem (root 글자 크기 기준)

width: 12.5rem;  /* 16px * 12.5 = 200px */
부모 (font-size: 20px)
rem : 부모와 무관하게 16px * 12.5 = 200px
em은 부모의 영향을 받고 rem은 받지 않는다. 그래서 중첩이 깊어질수록 rem이 예측하기 쉽다.

vw (화면 너비 기준)

width: 30vw;
vw : 창을 줄이면 같이 줄어든다

4. 색상 표기법

아래 5개는 rgba를 제외하면 모두 같은 색이다. 표기법만 다르다.
royalblue / #4169e1 / rgb(65,105,225) / rgba(65,105,225,0.4) / hsl(225,73%,57%)
색상 이름
#4169e1
rgb()
rgba() 투명도 0.4
hsl()
실무에서는 #4169e1 같은 16진수 표기를 가장 많이 쓰고, 투명도가 필요할 때만 rgba를 쓴다. hsl은 색상(H)·채도(S)·명도(L)로 다루므로 "같은 색의 밝기만 조금 바꾸고 싶을 때" 편하다.
