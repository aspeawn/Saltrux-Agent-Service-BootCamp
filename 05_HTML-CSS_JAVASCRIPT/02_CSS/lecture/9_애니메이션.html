애니메이션

@keyframes 규칙 : 애니메이션의 중간 상태를 정의한다.

 @keyframes 이름 { from { 시작 상태 } to { 종료 상태 } }의 형식으로 표현한다.
 0%, 30%, 100% 처럼 백분율로 여러 지점을 지정할 수도 있다.

animation 속성 : 정의한 @keyframes를 요소에 적용한다.

 animation-name              : 적용할 @keyframes의 이름
 animation-duration          : 한 번 재생되는 데 걸리는 시간
 animation-direction         : 반복 방향 (normal | reverse | alternate | alternate-reverse)
 animation-iteration-count   : 반복 횟수 (숫자 | infinite)
 animation-timing-function   : 진행 속도의 변화 (linear | ease | ease-in | ease-out | ease-in-out)

from - to 방식 (direction: alternate-reverse, 2회 반복 후 정지)

백분율 방식 (direction: alternate, 무한 반복)

animation-timing-function 비교

네 상자 모두 같은 거리를 같은 2초 동안 움직인다. 속도가 변하는 방식만 다르다.
linear
ease
ease-in
ease-out
linear는 처음부터 끝까지 같은 속도다. ease는 기본값으로, 천천히 시작해 빨라졌다가 다시 천천히 끝난다. ease-in은 천천히 시작해서 빠르게 끝나고, ease-out은 그 반대다.
