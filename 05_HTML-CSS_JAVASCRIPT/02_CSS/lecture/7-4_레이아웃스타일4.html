visibility

페이지에 특정 속성을 보이거나 보이지 않게 하는 속성

visibility: hidden — 안 보이지만 자리는 차지한다

visibility: hidden;

가운데 노란 상자가 사라졌지만 빨강과 초록 사이에 빈 자리가 그대로 남아 있다.

display: none — 안 보이고 자리도 차지하지 않는다

display: none;

이번에는 빈 자리도 없어서 빨강과 초록이 곧바로 붙는다. 둘의 차이가 바로 이것이다.

position: sticky

평소에는 내용과 함께 스크롤되다가, 지정한 위치에 닿으면 그 자리에 붙어서 고정되는 속성이다. 아래 상자 안에서 스크롤을 내려 보면 제목 줄이 위에 붙어 따라오는 것을 볼 수 있다.

position: sticky; top: 0;

float속성

페이지 내의 요소의 위치를 왼쪽이나 오른쪽으로 쌓이도록 지정하는 속성 (띄워서, 블럭 요소를 가로로 쌓기에 용이)

지금은 레이아웃 용도로 쓰지 않는다. float은 원래 '글 안에 이미지를 끼워 넣어 글자가 감싸고 흐르게 하는' 용도로 만들어진 속성인데, 가로 배치 수단이 달리 없던 시절에 레이아웃에 전용해서 쓰던 것이다. 부모가 높이를 인식하지 못해 clear로 뒤처리를 해야 하는 등 부작용이 많다. 지금은 가로 배치에 flex(7-5번)나 grid(7-6번)를 쓴다. 다만 오래된 코드나 기존 프로젝트에서 자주 마주치므로, 만났을 때 알아볼 수 있을 정도로만 익혀 둔다.
