grid 레이아웃

행과 열을 동시에 다루는 2차원 레이아웃 방식이다. flex가 한 방향(1차원)으로 늘어놓는 도구라면, grid는 페이지 전체를 격자로 나누는 도구다.

flex와 grid, 언제 무엇을 쓰나

한 줄로 늘어놓는 것(메뉴, 버튼 묶음, 아이콘+글자)은 flex, 화면 전체 뼈대나 카드 목록처럼 가로세로가 모두 있는 것은 grid를 쓴다. 실무에서는 grid로 큰 틀을 잡고 각 칸 안을 flex로 채우는 조합이 가장 흔하다.

fr 단위

fr(fraction)은 '남는 공간을 비율대로 나눠라'는 뜻이다. grid에서 가장 많이 쓰는 단위다.
grid-template-columns: 1fr 1fr 1fr;  /* 1:1:1 균등 분할 */

repeat()

같은 값을 여러 번 반복할 때 쓴다. repeat(4, 1fr)은 1fr 1fr 1fr 1fr과 완전히 같다.

4. grid-template-areas — 이름으로 배치하기 ★

영역마다 이름을 붙이고 그 이름을 격자 모양 그대로 적는다. CSS 코드의 생김새가 실제 화면 배치와 똑같아서, 읽기만 해도 구조가 파악된다.
grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";

빈 칸을 두고 싶으면 그 자리에 마침표(.)를 적는다.

5. (심화) 화면 크기에 따라 열 개수 자동 조절

당장 외울 필요는 없지만, AI가 만들어 준 카드 목록 CSS에서 자주 보게 되는 형태다. "칸의 최소 너비는 150px, 들어갈 수 있는 만큼 열을 만들어라"는 뜻이다. 브라우저 창 폭을 줄였다 늘였다 하면 열 개수가 저절로 바뀐다.
grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
