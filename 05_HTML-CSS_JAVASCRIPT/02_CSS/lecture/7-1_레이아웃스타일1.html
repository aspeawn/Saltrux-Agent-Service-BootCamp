width와 height

고정 크기

가변 크기

box-sizing (매우 중요!)

width와 height가 '무엇까지 포함한 크기'인지를 정하는 속성이다. 레이아웃이 조금씩 어긋나거나 삐져나오는 문제의 대부분이 여기서 나온다.

content-box (기본값)

width: 300px; padding: 20px; border: 5px solid;  /* 실제 폭 = 300 + 40 + 10 = 350px */
width는 300px이라고 썼지만 실제로는 350px을 차지한다.

border-box

width: 300px; padding: 20px; border: 5px solid; box-sizing: border-box;  /* 실제 폭 = 300px */
padding과 border가 안쪽으로 계산되어 정확히 300px이다.

가장 흔한 사고 : width 100% + padding

아래 두 상자는 CSS가 딱 한 줄만 다르다. 점선이 부모의 경계다.

width: 100%; padding: 20px;  /* 부모를 뚫고 나간다 */
부모 밖으로 삐져나온다
width: 100%; padding: 20px; box-sizing: border-box;  /* 딱 맞는다 */
부모 안에 정확히 들어간다

overflow

내용이 상자 크기보다 클 때 넘치는 부분을 어떻게 처리할지 정하는 속성이다.

overflow: visible;  /* 기본값. 상자 밖으로 그냥 넘쳐 나온다 */
이 글은 상자 높이보다 길어서 아래쪽 경계를 넘어간다. 넘친 글자가 그대로 보이기 때문에 아래 요소와 겹쳐 보일 수 있다.
overflow: hidden;  /* 넘친 부분을 잘라낸다 */
이 글은 상자 높이보다 길어서 아래쪽 경계를 넘어간다. 넘친 부분은 잘려서 보이지 않는다.
overflow: auto;  /* 넘칠 때만 스크롤바가 생긴다 */
이 글은 상자 높이보다 길어서 아래쪽 경계를 넘어간다. 스크롤바가 생기므로 내용을 모두 읽을 수 있다.
