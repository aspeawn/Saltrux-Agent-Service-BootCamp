flex 레이아웃

요소를 한 방향(가로 또는 세로)으로 배치하는 1차원 레이아웃 방식이다. float나 position으로 힘들게 만들던 배치를 몇 줄로 끝낼 수 있어서, 현재 웹 레이아웃의 기본이 되었다.

기본 구조

부모(flex container)에 display: flex를 주면 직계 자식들이 자동으로 flex item이 된다. 주 축(main axis)은 아이템이 늘어서는 방향이고, 교차 축(cross axis)은 그와 수직인 방향이다.
.container { display: flex; }

1. flex-direction — 주 축의 방향

flex-direction: row;  /* 기본값. 가로로 배치 */
1
2
3
flex-direction: column;  /* 세로로 배치 */
1
2
3
주의. column으로 바꾸면 주 축이 세로가 되므로, 아래에서 배울 justify-content가 '세로 정렬'로, align-items가 '가로 정렬'로 의미가 뒤바뀐다. flex에서 가장 헷갈리는 지점이니 꼭 기억한다.

2. flex-wrap — 넘칠 때 줄바꿈

flex-wrap: nowrap;  /* 기본값. 줄바꿈 없이 억지로 욱여넣어 아이템이 찌그러진다 */
넓은 아이템 1
넓은 아이템 2
넓은 아이템 3
넓은 아이템 4
flex-wrap: wrap;  /* 넘치면 다음 줄로 내린다 */
넓은 아이템 1
넓은 아이템 2
넓은 아이템 3
넓은 아이템 4

3. justify-content — 주 축(가로) 정렬

justify-content: center;
1
2
3
justify-content: space-between;  /* 양 끝에 붙이고 사이를 균등 분배 */
1
2
3
space-between은 내비게이션 바에서 로고는 왼쪽, 메뉴는 오른쪽에 둘 때 가장 많이 쓰인다.

4. align-items — 교차 축(세로) 정렬

align-items: stretch;  /* 기본값. 컨테이너 높이를 꽉 채운다 */
1
2
align-items: center;
1
2
★ 가로세로 완전 가운데 정렬은 이 두 줄이면 끝난다. 자주 쓰게 되니 외워 두면 좋다.
justify-content: center;  align-items: center;
정중앙

5. gap — 아이템 사이 간격 ★

gap은 아이템 '사이'에만 간격을 넣는다. margin으로 간격을 주면 맨 끝 아이템 바깥쪽에도 붙어서 마지막 요소만 따로 제거하는 처리가 필요한데, gap은 그럴 일이 없다.
gap: 0;  /* 간격 없음 */
1
2
3
gap: 20px;  /* 아이템 사이에만 20px. 양 끝에는 붙지 않는다 */
1
2
3

6. flex — 남는 공간 나눠 갖기 ★

아이템에 주는 속성이다. flex: 1은 "남는 공간을 차지해라"는 뜻이고, 여러 아이템에 주면 숫자 비율대로 나눠 갖는다.
1번만 flex: 1;  /* 1번이 남는 공간을 전부 차지한다 */
flex: 1
고정
고정
1번 flex: 2;  2번 flex: 1;  /* 2:1 비율로 나눠 갖는다 */
flex: 2
flex: 1
사이드바는 고정 폭, 본문은 나머지를 모두 차지하는 레이아웃이 이 속성으로 만들어진다.
