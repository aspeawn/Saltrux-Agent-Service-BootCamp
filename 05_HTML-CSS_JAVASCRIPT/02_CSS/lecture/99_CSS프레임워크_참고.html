2. Tailwind - 작은 조각을 조립하는 방식

완성품 대신 속성 하나짜리 클래스를 준다. 이것을 여러 개 붙여서 원하는 모양을 만든다. 이런 방식을 유틸리티 우선(utility-first)이라고 부른다. 

<button class="bg-blue-600 text-white px-4 py-2 rounded">버튼</button>

    bg-blue-600  -> background-color
    text-white   -> color
    px-4 py-2    -> padding 좌우 / 상하
    rounded      -> border-radius
flex items-center gap-3 7-5번에서 배운 flex와 같은 것이다

클래스 이름이 CSS 속성과 거의 1:1로 대응한다는 점이 중요하다. flex items-center gap-3은 결국 display:flex; align-items:center; gap:12px;이다. 순수 CSS를 알면 Tailwind는 따로 배울 것이 거의 없다.

3. 같은 버튼, 세 가지 방법

세 버튼은 거의 같은 모양이다. 만드는 방법만 다르다.

직접 CSS : <button class="my-button">      (style에 .my-button 정의)
Bootstrap : <button class="btn btn-primary">
Tailwind  : <button class="bg-blue-600 text-white px-4 py-2 rounded">
