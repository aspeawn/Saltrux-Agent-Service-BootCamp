변형(transform)과 트랜지션(transition)

transform은 "어떻게 바뀔지", transition은 "얼마 동안 바뀔지"를 정한다. 둘은 거의 항상 짝으로 쓰인다. 아래 상자들에 마우스를 올려서 확인한다.

1. transform — 요소 변형하기

요소를 이동·확대·회전·기울일 수 있다. 중요한 특징은 변형해도 원래 차지하던 자리는 그대로라는 점이다. 옆 요소를 밀어내지 않기 때문에 레이아웃을 건드리지 않고 시각 효과만 줄 수 있다.

translate — 이동

transform: translate(50px, 20px);
translate

scale — 확대·축소

transform: scale(1.5);
scale

rotate — 회전

transform: rotate(45deg);
rotate

skew — 기울이기

transform: skew(20deg, 10deg);
skew

여러 변형 한 번에

공백으로 이어 쓰면 왼쪽부터 차례로 적용된다. 순서를 바꾸면 결과가 달라진다.
transform: rotate(15deg) scale(1.3);
rotate + scale

transform-origin — 변형의 기준점

기본값은 요소의 정중앙이다. 아래 상자는 왼쪽 아래 모서리를 축으로 회전한다.
transform-origin: left bottom;
origin 변경

2. transition — 시간에 걸쳐 바꾸기

위 상자들은 마우스를 올리는 순간 뚝 끊기듯 바뀐다. transition을 주면 그 변화가 부드럽게 이어진다.

transition-duration — 지속 시간

transition-duration: 0.5s;
0.5초에 걸쳐

transition-property — 대상 속성 고르기

아래 상자는 background만 대상으로 지정했다. 너비는 즉시 바뀌고 색만 부드럽게 바뀐다.
transition-property: background;  transition-duration: 0.5s;
background만

transition-timing-function — 속도 곡선

같은 1.5초라도 어떻게 가속·감속하는지가 다르다. 세 개를 동시에 비교한다.
linear(일정) / ease(기본값, 느리게-빠르게-느리게) / ease-in-out
linear
ease
ease-in-out

transition-delay — 시작 지연

transition-delay: 1s;
1초 후 시작

단축 표기

실무에서는 개별 속성보다 이 한 줄 형태를 압도적으로 많이 쓴다.
transition: transform 0.3s ease-out;  /* 대상 지속시간 속도곡선 */
살짝 떠오르기
위 상자처럼 "hover하면 살짝 뜨고 커지는" 효과는 카드·버튼 UI의 가장 흔한 관용구다.
