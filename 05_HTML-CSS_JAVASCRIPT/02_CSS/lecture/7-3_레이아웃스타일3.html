여백 관련 속성

기준 div

padding

테두리와 컨텐츠 영역 사이의 거리를 조절하는 속성
padding: 100px;
콘텐츠 영역
padding-top: 50px; padding-left: 100px;
콘텐츠 영역

margin

box 레벨(block)이나 inline 레벨의 요소들 간의 간격을 조절하는 속성

파란 점선은 여백을 눈으로 보기 위해 두른 것이다. 점선과 노란 상자 사이가 margin이다.
margin: 50px;   /* 네 방향 모두 */
콘텐츠 영역
margin-top: 50px; margin-left: 50px;   /* 위와 왼쪽만 */
콘텐츠 영역
두 상자의 왼쪽·위 여백은 같다. 오른쪽과 아래 여백이 있고 없고가 다르다.

margin: auto — 가운데 정렬

좌우 여백을 자동으로 똑같이 나눠 준다. width가 지정된 블록 요소에만 통한다.
margin: auto;
콘텐츠 영역
