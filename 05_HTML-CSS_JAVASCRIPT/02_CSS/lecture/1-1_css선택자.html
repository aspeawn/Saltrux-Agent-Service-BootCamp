CSS 선택자

선택자(selector)는 "어떤 태그에 스타일을 적용할지 지목하는 문법"이다. CSS의 절반은 선택자이고, 나머지 절반이 속성이다.

1. 기본 선택자

선택자문법의미
전체*모든 태그
태그p해당 태그 전부
아이디#id명id가 일치하는 태그 (문서에 하나만)
클래스.클래스명class가 일치하는 태그 전부
  • 태그 선택자로 파랗게 칠해진 항목이다.
  • 아이디 선택자로 선택된 항목이다.
  • 클래스 선택자로 선택된 항목이다.
  • 클래스는 이렇게 여러 개에 붙일 수 있다.
id는 문서에서 유일해야 하고 class는 여러 곳에 재사용한다. 실무에서는 class를 압도적으로 많이 쓴다.

2. 속성 선택자

태그가 가진 속성의 값을 기준으로 선택한다.
문법의미
[속성="값"]값이 정확히 일치
[속성^="값"]값으로 시작
[속성$="값"]값으로 끝남
[속성*="값"]값을 포함

data-type이 정확히 fruit인 문단이다.

data-name이 ko로 시작하는 문단이다.

data-name이 _end로 끝나는 문단이다.

data-name에 mid가 포함된 문단이다.

3. 관계 선택자

태그 사이의 위치 관계로 선택한다. 공백 하나 차이로 의미가 완전히 달라지므로 주의한다.
부모 > 자식   : 바로 아래 자식만
부모   후손   : 몇 단계 아래든 전부
A + B        : A 바로 다음 형제 하나
A ~ B        : A 뒤의 형제 전부

자식(>)과 후손(공백)

  • 직계 자식이라 왼쪽에 초록 선이 붙는다.
  • 직계 자식이다. 이 span은 후손 선택자로 선택된다.
    • 이 항목은 한 단계 더 안쪽이라 초록 선이 붙지 않는다.

형제(+, ~)

기준이 되는 문단이다.

바로 다음 형제라 노란 배경(+)과 점선(~)이 모두 적용된다.

그 다음 형제라 점선(~)만 적용된다.

마찬가지로 점선(~)만 적용된다.

4. 구조 가상 클래스

형제들 사이에서 몇 번째인지로 선택한다. 목록이나 표에 줄무늬를 넣을 때 자주 쓴다.
:first-child / :last-child / :nth-child(2n) / :not(조건)
  • 첫 번째 (first-child)
  • 두 번째 (짝수라 글자색이 바뀐다)
  • 세 번째
  • 네 번째 (짝수)
  • 다섯 번째 (last-child)

5. 상태 가상 클래스 ★

사용자의 동작이나 요소의 상태에 따라 스타일이 바뀐다. JavaScript 없이 CSS만으로 상호작용을 표현할 수 있는 부분이다.
:hover(마우스 올림) / :active(누르는 중) / :focus(입력 중) / :checked(선택됨) / :disabled(비활성)
