배경색과 배경 이미지

1. background-color 속성 : 요소의 배경색을 지정한다.

 선택자 { background-color : 색상명 | 16진수 | rgb() | rgba() | hsl(); }의 형식으로 표현한다.
아래 5개는 rgba의 투명도를 빼면 모두 같은 색이다. 표기법만 다르다.
royalblue
#4169e1
rgb()
rgba() 0.4
hsl()
div의 배경색은 부모에게서 상속되지 않는다. 필요한 요소마다 따로 지정해야 한다.

2. background-clip 속성 : 배경을 어디까지 칠할지 정한다.

 선택자 { background-clip : border-box | padding-box | content-box; }의 형식으로 표현한다.
세 상자 모두 흰 배경에 8px 점선 테두리와 20px 안쪽 여백을 갖고 있다. 점선 사이의 틈으로 흰 배경이 어디까지 칠해졌는지 확인한다.
border-box (기본값) : 테두리 아래까지 칠한다
padding-box : 테두리 안쪽까지만 칠한다
content-box : 글자 영역까지만 칠한다

3. background-image 속성 : 요소의 배경에 이미지를 넣는다.

 선택자 { background-image : url("이미지경로"); }의 형식으로 표현한다.

background-repeat — 반복 여부

기본값은 repeat이다. 이미지가 요소보다 작으면 가로세로로 계속 반복된다.
순서대로 repeat(기본값) / repeat-x(가로만) / no-repeat(반복 안 함)이다.

background-size — 크기

auto는 원래 크기 그대로, cover는 비율을 유지한 채 요소를 꽉 채운다(잘릴 수 있다), contain은 비율을 유지한 채 이미지 전체가 보이도록 맞춘다(빈 곳이 생길 수 있다). 실무에서 배경 사진을 넣을 때는 거의 항상 cover를 쓴다.

background-position — 위치

순서대로 center / right bottom / 30px 50px 이다. 키워드, 백분율, px 단위를 모두 쓸 수 있다.

4. background-attachment 속성 : 스크롤할 때 배경이 따라 움직일지 정한다.

 선택자 { background-attachment : scroll | fixed; }의 형식으로 표현한다.
기본값은 scroll로, 내용과 함께 배경도 움직인다. 아래 상자는 fixed라서 안쪽 글자를 스크롤해도 배경 사진은 제자리에 고정된다.
