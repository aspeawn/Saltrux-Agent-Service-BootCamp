1일차 : 글자 관련 태그

오늘 배운 내용

HTML은 문서의 구조를 표현하는 마크업 언어이다. 태그의 의미에 맞게 쓰는 것이 중요하다.

인용문 문구입니다.
태그는 모양이 아니라 의미로 고른다.

기억할 태그들

  • strong : 중요한 단어를 굵게
  • em : 강조하고 싶은 부분을 기울임으로
  • mark : 새로 배운 용어에 형광펜 효과
